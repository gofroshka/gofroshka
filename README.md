🧑‍💻 В здоровом коде — здоровый слоп

Народная мудрость AI-разработчика.

Поспешишь — весь проект наслопишь.

Один when — хорошо, а десять if — лучше.

В моноклассе десять абстракций водится.

Без Клода не заслоперить и класса два.

На Клода надейся, а слоп проверяй.

Скупой пишет дважды, агент — четырежды, ещё и заслопит.

Не было бы слопа, да AI помог.

Где один агент не справится — там пять агентов конфликт устроят.

Семь раз запромпть — один раз задеплой.

Слово не воробей, а git reset --hard ещё никто не отменял.

Что написано пером — перепишется Клодом.

Старый код борозды не портит, пока агент его не отрефакторит.

Любишь слоп писать — люби и CI чинить.

Не откладывай на завтра то, что агент может сломать сегодня.

У семи агентов репозиторий без хозяина.

Дарёному коду в тесты не смотрят.

Тише едешь — меньше токенов жжёшь.

С кем поведёшься — от того и зависимость в package.json.

Яблоко от яблони недалеко падает, а абстракция — на три директории выше.

Код кодом вышибают.

Бесплатный токен только в мышеловке.

Работа не волк — агент сам закоммитит.

В чужой репозиторий со своим промптом не ходят.

После драки git blame не смотрят.

Нет тестов — нет проблем.

Не баг, а простор для следующего промпта.
